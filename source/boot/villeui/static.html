Qooxdoo + Native CSS = 🔥

Flexible styling using native CSS.

⚒ Built with CSS

Styles are exposed as .css files – styles are performant and do not have any runtime overhead.

☯ Extends only core widgets

All Ville UI widgets either directly extend complex widgets (i.e. qx.ui.form.Button) or Qooxdoo's core widget (qx.ui.core.Widget). Everything is a Qooxdoo widget.

✺ Override anything

All component styles can be overriden with inline styles. All Ville UI widgets expose Content Element functions such as setStyles and addClass (among others) for simple and direct changes as needed.
